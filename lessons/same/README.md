# Same

Two parallel experiments start with identical input sets. The left passes them
through two operations. Choose one operation on the right whose action agrees
on the entire three-element domain. The copies are explicitly paired input
sets, not duplicates created in a single conserved collection.

All three inputs are shown in each experiment, so equality is never inferred
from a single fixed point. One incorrect candidate reverses the order of the
two noncommuting operations. Another is identity. Each example has exactly one
matching candidate. Tests enumerate every input independently, including a
counterexample where two different maps agree on just one input.

The single selected tile can replace a composite construction conceptually.
Cross-lesson dragging of a learner-created operation is future work, not a
capability of this prototype. Read this folder and `AUTHORING.md` first.
