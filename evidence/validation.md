## What changed and what was checked

Connections is compared with ordered edge sets for all 512 binary relations on
three vertices. Matrix columns act on independently constructed basis vectors.
Directed cell toggles, symmetric OR closure, mirrored undirected edits, and
self-loops are checked. The exported script supports matrix edits, endpoint
selection, successful drags, canceled drags, and exact relation restoration.

Through is compared with an independent join of two edge lists for 3,584 relation
pairs. Every entry is checked against its explicit intermediate identities.
Contrasts include zero, one, two, and three routes and an inverse composition
producing identity. Input-graph changes recompute the result. Result selection
never edits its count. Heat mode preserves the underlying relations.

Fold samples all three examples through 101 phases and checks unit edges,
diagonals, coplanarity, area, and every shared hinge. The final cube has eight
vertices, twelve edges each shared by two faces, and six faces. The staged lid
stays above the box while closing. CSS matrices are independently applied to
local corners and compared with the model's projected vertices across cameras
and stage sizes. Direct grip movement, orbiting, keyboard controls, cancellation,
restore, bounded playback, and reduced motion execute in the exported document.

The existing foundation, cycle, inverse, and equality checks continue to pass.
Catalog tests exercise both delivery editions, state restoration, stale-window
rejection, malformed fragments, a synthetic 24-lesson catalog, and separation
of lesson targets on narrow rows. The map now uses at most two nodes per row
below a 360-pixel map width. A new lesson's mathematical and interaction checks
are discovered locally from its manifest; no central lesson list is required.

Build discovery excludes drafts, rejects missing dependencies and cycles,
confines includes, escapes embedded script terminators, and exercises the draft
generator in an isolated temporary project. Offline inspection checks every
export for unresolved includes and external runtime resources.

## Visual inspection

The Connections and Through desktop and narrow vector scenes are generated by
the exported scripts and native-object positions. Fold scenes in `scenes/` come
from `render-fold.cjs`, which projects the emitted CSS-plane matrices into SVG.
This snapshot helper sorts planes for inspection; the application itself uses
the browser's 3D compositor. The desktop and narrow scenes were rasterized with
Inkscape and inspected. The nine-node constellation was inspected as well.

The graph/matrix layout keeps 48-pixel matrix targets and stacks at a 620-pixel
stage width. Its CSS breakpoint accounts for the app padding (656 viewport
pixels minus 36 pixels gives a 620-pixel stage). Short screens can scroll.
Static vector scenes do not include actual browser control styling, focus,
CSS media-query layout, compositor behavior, or native input rendering.

## Practical limits

No browser/iframe integration or real touch-device test was completed for this
revision. The session's local-document preview route was blocked earlier; no
alternative browser-control route was used. A DOM harness cannot validate
actual pointer capture, focus transitions, iframe policy, local-file behavior,
audio permissions, Safari behavior, CSS 3D compositing, or subjective motion feel.
Those remain practical device checks. These are not browser screenshots.

The user reported enjoying the earlier collection in the desktop application.
That is feedback on the previous artifact, not verification of all new controls.
No accessibility conformance, learner-study, or age-specific effectiveness claim
is made. Native accessible labels and keyboard equivalents are implemented.

The first three source views still share the foundation engine. Subsequent
lessons own independent models and views. Cross-lesson transfer of learner-built
operations, context browsing, arbitrary polyhedron nets, WebGPU, and the
probability peg board remain future work. Through counts routes over integers;
Fold is a coordinated rigid-hinge mechanism, not a physical paper simulation.

Only visits persist across refreshes. Lesson snapshots remain in memory during
one collection session. Pause acknowledgment has a 180 ms fallback to the latest
known snapshot. Every standalone lesson works without a catalog dependency.
The output is prepared for a GitHub Pages repository; no repository was created
or deployed in this task.
